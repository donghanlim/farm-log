# 팜로그 실문장 10건 수집 시트 (Week 02 · 2026-09-14~20)

목표: 팜로그 실제 농가 문장 10건 확보 시 동일 harness 재실행 (직불금·친환경 제출형)

## 1. 페르소나·타겟 (이번 주 고정)

- 페르소나 A — 직불금형: 60대 벼·밭작물 소농, 매년 공익직불금 이행점검용 영농일지 제출. 폼 앱 어려움, 장갑 낀 손이라 음성 선호. 페인 = "안 내면 감액".
- 페르소나 B — 인증유지형: 친환경(유기/무농약) + GAP 유지 농가. 방제·투입자재·출하 누락 시 인증 취소 리스크. 페인 = "재입력 지옥".
- 제출 연결: 직불금 영농일지(작업일/필지/작업) + 친환경 자재·방제 기록 + GAP 방제이력부/출하기록.

## 2. 수집 규칙 (오염 방지)

1. 원문 그대로 보존 (STT 결과 수정 금지, 날짜 2011→2021 같은 오인식도 메모에만 기록)
2. 먼저 리마인드하지 않기 (자발성 측정 — Phase 0-1 콘시어지 규칙)
3. 동의 먼저: 원문 보존·보관기간·삭제요청 경로·외부모델 처리 여부 고지, 농가별 접근권한 분리
4. 사진 있으면 EXIF 시각·GPS는 별도 컬럼에 기록 (본문에 섞지 않기)
5. 모호하면 비우기: 라벨링 시 들리지 않은 값은 null + missing에 기록 (임의추정 금지)

## 3. 10건 구성 (4-3-3)

- 직불금 4건 (F01~F04): 파종/관수/예찰/수확, 날짜·필지 포함/누락 섞기
- 친환경 3건 (F05~F07): 무농약 자재 살포, 병해충 방제, 제초 — 제품명 모호 1건 포함
- 인증제출 3건 (F08~F10): 방제 희석배수, 수확량, 출하 — 수량·단위 모호 1건 포함
