## 3. 환경 제약과 `[blocked]`

### `[blocked]` 실제 모바일 및 headless 브라우저 검증

- 연결된 브라우저의 `setViewportSize`가 지원되지 않았다.
- 별도 Playwright headless Chrome 실행도 환경 신호 권한 제약으로 SIGABRT/EPERM 실패.
- 이를 우회하기 위해 사용자 브라우저 보안 설정을 낮추거나 프로필을 조작하지 않았다.
- `scripts/check-workspace-browser.mjs`에는 390px 화면·오버플로·입력 보존·CSV·동작 시나리오를 작성했지만 이번 세션에서 성공 실행한 증거가 아니다.
- 최소 다음 확인: 일반 개발 터미널에서 이 스크립트 실행, 이후 실제 Android/iPhone에서 터치·키보드·글씨·인식 권한 확인. 현재 loopback 주소는 휴대폰에서 Mac으로 접속하는 배포 주소가 아니다.

### 기존 프로세스 갱신 제약

- 기존 8880 프로세스에 SIGTERM 권한이 없어 보존했다.
- 중간 8881 시연 프로세스도 같은 제약으로 정상 재시작할 수 없었다.
- 최종 원장은 `.local-data/workspace-preview/`로 분리했고, 이 작업이 만든 합성 시연 journal만 복사했다. 사용자 원장·실제 미디어를 이동·삭제하지 않았다.
- 최종 UI와 최신 backend는 51239에서 함께 확인했다. 8880/8881이 최종 서버라고 보고하지 않는다.

## 4. 독립 검토와 반영

- 수동 초안 생성 응답 유실 시 중복 생성 위험: requestKey + payload digest + 같은 journal 이벤트로 보완. 재시도·재시작 테스트 통과.
- 필지 선택이 수동 작목을 덮어쓰는 위험: 직접 수정 여부를 보존, 기존 세션·정정은 작목 유지.
- 농장 저장 후 조회 실패 시 구 profile로 돌아가는 위험: POST 결과를 즉시 반영하고 조회 실패를 별도 안내.
- draft 작업일과 session context 불일치: workedAt 동기화.
- 선택값·메모 원문 누락: 직접 선택 요약과 메모를 구분해 보존.
- 검토 이력 UI 미노출: correction chain 전체 reviewHistory 제공·표시.
- 관리자 CSV 미기재 의미: null을 미기재로 표현. 운영 CSV와 영농일지 CSV의 서로 다른 목적·필터 경계를 문서화.

## 5. 미검증·미구현

- 실제 농업인 입력시간 20초 이하, 고령자 이해도, 필드 정확도, 고객 지속성.
- 실제 기기·Safari·스크린리더·WCAG·PWA 설치·완전 오프라인.
- 기존 로컬 AI/STT/OCR의 이번 환경 재실측.
- 관리자 CSV의 OS 다운로드 성공은 이번 실제 브라우저에서 별도로 검증하지 않음. CSV 생성 코드와 필터 렌더·기존 서버 내보내기는 코드/테스트 범위.
- 사용자 인증·권한·농가 분리·개인정보 처리 정책·다중 서버·백업·복구.
- 외부 배포·실제 농가 데이터 수집·알림 발송·유료 호출·자동 제출 미실행.

기초 MVP 완성은 위 범위의 **로컬 연결 흐름 구현**을 의미한다. 상용 제품 또는 실제 농가 검증 완료가 아니다.
