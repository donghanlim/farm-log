# 팜로그 (FarmLog)

> 농민이 밭에서 말하고 찍기만 하면, AI가 근거가 남는 영농일지와 친환경 인증·직불금 제출서류 초안으로 정리해주는 서비스

## 왜 만드나

친환경(유기·무농약)·GAP 인증 농가와 공익직불금 농가는 작업 내용과 자재 사용 이력을 기록·증빙해야 합니다. 하지만 현장에서는 일하는 도중에 기록하기 어렵고, 고령 농업인에게 많은 입력칸은 큰 부담입니다. 그래서 기록은 기억에 의존해 몰아 쓰거나 심사 직전에 사후 재구성되는 경우가 많습니다.

팜로그는 순서를 바꿉니다.

1. **음성 한마디·사진 한 장으로 입력**
2. **빠진 필수 항목만 AI가 버튼형 질문으로 되묻기** (최대 2회)
3. **모든 일지·서류 항목에 원본 기록 연결** — 값의 출처를 추적
4. **모르면 비우기** — AI가 들리지 않은 값을 추측해 채우지 않고 사용자 확인을 받음

## AI 역할 분리

| 단계 | 담당 | 비고 |
|---|---|---|
| 음성 → 텍스트 | STT (Whisper 계열 등 비교) | 날짜·수량은 반드시 사용자 확인 |
| 사진 → 자재명·수량 | OCR / 비전 모델 | 근거 자료로 첨부 |
| 텍스트 → 영농일지 항목 | LLM 구조화 출력 | 확신 낮은 항목은 null + 보완 질문 |
| 농약 적합성 판단 | 규칙 + 공공 데이터 | **AI에 맡기지 않음** |
| 제출서식 생성 | 템플릿 | **AI에 맡기지 않음** |

## 현재 구현 상태 (2026-10)

- **농업인용 간편 기록 화면 + 관리자 화면**이 같은 기록 원장으로 연결된 반응형 웹 MVP (`src/workspace/`)
- 저장 → 보완 요청 → 원본 보존 정정 → 재확인 흐름, 필터·CSV 내보내기
- 원장은 append-only: 원본은 수정하지 않고 정정은 새 기록으로 남김
- 음성(브라우저 Whisper)·사진(Tesseract OCR)·로컬 LLM을 연결한 실험용 입력 경로 (`src/app-server.mjs`)
- 자동 테스트: `node --test`

**아직 하지 않은 것:** 실제 농가 시범 운영, 로그인·농가별 권한, 클라우드 배포, 농약 판정 연동, 공식 인증서식 출력. 현재 데모는 시험용(합성) 기록만 사용합니다.

## AI 품질 검증 (evals)

- 시험용 기록 30건·블라인드 20건으로 여러 LLM의 항목 추출을 같은 조건에서 비교 ([`evidence/`](evidence/))
- 반복 확인된 실패: 모델이 애매한 작물·필지·수량을 높은 확신으로 채워 넣음 → "모르면 비우기"를 코드 단계 검사로 강제하는 설계로 반영
- **주의:** 현재 수치는 합성 데이터 기준이며, 실제 농가 성능이 아닙니다. 실제 농가 발화로 정답 데이터를 만든 뒤 재측정합니다.
- 평가 과정 기록: [evals-archive](https://github.com/donghanlim/evals-archive)

## 목표 (2026년 12월)

- 홍성 가족 농지를 포함한 5개 농가 시범 운영, 실제 기록 100건 이상
- 기록 1건 20초 이내 / 핵심 항목 정확도 95%, 전체 90% / 보완 질문 평균 1.2회 이하
- 친환경 인증 또는 공익직불금 서식 초안 1종 생성 후 농가 확인

※ 위 수치는 목표이며 아직 달성한 성과가 아닙니다.

## 로컬 실행

```bash
npm install   # 최초 1회 (서버는 Node 내장 모듈 사용)
npm run preview
# 출력된 주소의 /mvp (농업인), /admin (관리자)
node --test   # 테스트
```

Node.js 22 이상.
